# 검색 품질 점검표

| 번호 | 검색 질문 | 기대 결과 | 제외 결과 | 0건 조건 |
|---:|---|---|---|---|
| 1 | 도쿄 직항 항공권 검색 | 노선 설명이나 항공사명에 도쿄·직항이 있는 왕복 항공권 | 경유가 포함된 조합, 도쿄와 무관한 노선 | 존재하지 않는 도시명 검색 |
| 2 | 총액 50만원 이하 왕복 직항 이코노미 | 양편 직항·이코노미·총액 50만원 이하 항공권이 싼 순으로 표시 | 경유 조합, 비즈니스·퍼스트, 총액 50만원 초과 | 같은 조건에서 좌석등급을 퍼스트로 변경 |
| 3 | 노선별·체류일수별 총액 요약 | 노선과 체류일수별 평균 왕복 총액이 집계되어 표시 | 좌석등급이 섞여 평균이 왜곡된 결과 | 체류일수 30박 이상 |

## 0건 조건의 근거

2번의 0건 조건은 데이터 생성 규칙에서 나온다. 인천→도쿄 왕복 퍼스트클래스는 총액 하한선을 50만원보다 높게 설정하므로, 같은 조건에서 좌석등급만 퍼스트로 바꾸면 결과가 0건이 되는 것이 정상이다. 0건은 검색이 실패한 것이 아니라 조건을 만족하는 상품이 없다는 뜻이다.
