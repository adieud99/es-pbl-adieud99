# PBL 시작 카드

- 프로젝트 주제: 국내선·국제선 왕복 항공권 검색
- 사용자는 누구인가: 출발지·도착지와 대략의 기간만 정해 둔 여행객
- ES로 찾게 할 문서 1건은 무엇인가: 왕복 항공권 1건 (가는 편과 오는 편이 짝지어진 조합)
- 사용자가 입력할 검색 질문 1: "도쿄 직항"을 노선 설명이나 항공사명에서 검색한다.
- 사용자가 입력할 검색 질문 2: 인천에서 도쿄로 가는 왕복 직항 이코노미 중 총액 50만원 이하인 항공권을 총액이 싼 순으로 찾는다.
- 사용자가 입력할 검색 질문 3: 노선별 평균 왕복 총액과 체류일수별 평균 총액을 확인한다.
- 필터에 사용할 분류 field 후보: 국내/국제 구분, 좌석등급, 항공사, 출발 공항, 도착 공항, 직항 여부
- 정렬에 사용할 숫자·날짜 field 후보: 왕복 총액, 가는 편 출발 일시, 체류일수, 총 비행시간
- Dashboard에서 답할 질문 1: 어느 노선을 며칠 일정으로 잡을 때 왕복 총액이 가장 낮은가?

## 범위 확인

- 웹사이트 전체를 만드는 과제가 아닙니다. ES index, 검색 요청, 분석·Dashboard를 완성합니다.
- 실제 개인정보·고객 데이터는 사용하지 않습니다.
- 최소 1,000건, 권장 5,000~10,000건의 합성 데이터를 사용합니다.
